# Data

The raw CSV files are not stored in this repository (about 96 MB). To reproduce the project:

1. Download the dataset **DataCo Smart Supply Chain for Big Data Analysis**:
   - Mendeley Data (original source): https://data.mendeley.com/datasets/8gx2fvg2k6/5
   - Kaggle copy: https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis
2. Place `DataCoSupplyChainDataset.csv` in this folder. The file is encoded as latin-1.
3. The files `DescriptionDataCoSupplyChain.csv` (column descriptions) and `tokenized_access_logs.csv` (web logs) are not used by the report.
